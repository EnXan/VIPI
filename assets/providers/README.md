# Provider icons

Monochrome provider marks used in the project README, in VIPI Ink with a Paper
variant for dark mode. Most paths come from [Simple Icons](https://simpleicons.org/)
15.10.0 (CC0-1.0). `liquidai.svg` and `typesafe.svg` embed a 256 px mask made
from the providers' published logos; Liquid AI uses only its symbol. The marks remain trademarks of their
owners and only identify which provider supplies a model.
