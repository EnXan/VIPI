# VIPI Assets

All brand files for VIPI. The rules are in `brand/vipi-brand.html` (open it in a browser).

| Folder | Contents |
|---|---|
| `logo/svg` | Horizontal and stacked logo, each in white (for dark backgrounds) and black (for light backgrounds) |
| `logo/png` | The same logos as PNG at 512, 1024 and 2048 px wide, transparent background |
| `icon` | App icon dark/light (SVG, 1024, 512, 192 px), `apple-touch-icon.png`, `favicon.svg`, `favicon.ico`, `favicon-16/32/48.png` |
| `motion` | Reveal animation as animated SVG, MP4 and GIF |
| `social` | Link preview image (1200 × 630) |
| `tokens` | Colors and typefaces as CSS variables and JSON |
| `brand` | Brand guidelines as an HTML page |
| `source` | `build_logo.py` regenerates all logo SVGs from the pixel grid |

Quick rules:
- VIPI is the full name and is never spelled out.
- The logo appears only in Ink `#0B0C10` or Paper `#F2F3F5` / white.
- Clear space: 2 grid pixels on every side. Minimum width 96 px (stacked 48 px); below that, use the favicon.
- Typefaces: Geist and Geist Mono (SIL Open Font License, Google Fonts).
