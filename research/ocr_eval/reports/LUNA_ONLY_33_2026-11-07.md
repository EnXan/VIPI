# Luna-only diagnostic: 33 images, 2026-11-07

One direct `gpt-6-luna` Responses transcription per image, using the existing `LunaEngine`: reasoning `none`, image detail `original`, full image at native resolution after EXIF orientation and RGB conversion. No Google OCR, recovery review, transformations, crops, retry, reference text in prompts, or final injection detector. All 33 API requests completed; one returned an empty transcript, which receives zero credit. No attempts were repeated. This tests the existing single-pass adapter, not Luna with tuned prompting or higher reasoning.

## Selection and comparison boundary

Three images per eight main categories (24 core images), selected by first/middle/last sorted stable ID. TextOCR instead uses the three previously discussed difficult examples: grill, brochure and book spines. The two remaining Anamorpher images and seven otherwise-uncovered obfuscation examples bring the deduplicated sample to 33. Every existing category, obfuscation, technique and Anamorpher family is represented. Facets overlap; additional images also belong to the main categories, but the main-category table below uses only its three core examples. This is a deliberately small development diagnostic, not an unbiased sample or a new general benchmark.

Inputs use dataset revision `2278db5db5dfe1ba8b930cc9b3888962c2672b35`. Image and exact reference hashes were checked against the retained 1,113-entry benchmark before inference. Local speed (Tiny + d1) and cloud defaults (Google Vision + OpenAI Decisions) reuse saved final outputs from that run; neither was rerun. Source hashes/snapshot, prompt, selection reasons, baseline run IDs, raw Luna responses, usage, transcripts and exact references are retained in the run manifest and the [JSON bundle](LUNA_ONLY_33_2026-11-07.json).

Luna supplies no word boxes. All configurations are therefore rescored with the same **text-only diagnostic**: existing tolerant and literal word matching, distinct observations for repeated words, known reading order retained, and unordered region references matched against transcript words at a shared synthetic location. This intentionally removes localization and independent-region geometry conflicts. No model geometry is invented. These percentages must not be substituted into the spatial product benchmark. Coverage concerns only the annotated scope, sometimes payload-only; extra or invented text is not penalized. It measures OCR recovery, not injection detection.

Luna transcribed only `HARRY`, `POTTER`, and `J.K. ROWLING` on the book-spine image: 4/72 tolerant and literal words. Cloud defaults recover 22/72 in this text-only diagnostic, compared with 21/72 in the published spatial benchmark. Retokenizing final text instead of native word observations can also change counts; all three configurations use the same transcript-token representation here. The grill improves slightly over Google, while the brochure loses words. These cases give no support for assuming that replacing Google with single-pass Luna will resolve difficult layouts. Anamorpher also remains difficult: Luna recovers only 1/21 reference words across three images (4.76%), versus cloud defaults 15/21 (71.43%). The selected base64 payload is transcribed with substantial character corruption and receives zero word credit; this single encoded string is one reference word. These tiny subset counts are diagnostic examples, not stable category accuracy estimates. The experiment does not isolate why Luna omitted the spine titles; orientation, localization, image representation and prompting remain possible factors.

## Duration and fees

The 33 per-image wall intervals sum to **97.43 seconds**, averaging **2.95 seconds/image**. Intervals include image decoding, API request/response, artifact writing and scoring, and exclude initial setup and gaps between images. They are not a controlled latency comparison with the earlier local/cloud benchmark.

Retained Responses usage: 99,272 input tokens, including 0 cache reads and 94,895 cache writes, plus 3,854 output tokens. Estimated API fee: **$0.014227 total**, **$0.000431/image**; all 33 attempts have usage. Output tokens are charged here, unlike the earlier Decisions review calls.

[Official list rates](https://developers.openai.com/api/docs/pricing), checked 2026-11-07: standard global short-context input $0.10/M, cached reads $0.01/M, default 30-minute cache writes $0.125/M, output $0.50/M. Cache reads/writes are disjoint subsets of input tokens. This is a usage estimate, not an invoice; quota, discounts, taxes, premium processing and hardware/electricity are excluded. Raw usage and model response IDs are in the bundle.

## Reproduce and validate

From the same source checkout with the pinned dataset, saved product-run artifacts and `OPENAI_API_KEY` configured:

```bash
uv run python -m research.ocr_eval.experiments.luna_only runs/experiments/luna-new --prepare-only
uv run python -m research.ocr_eval.experiments.luna_only runs/experiments/luna-new
uv run pytest -q tests/research/test_luna_only.py tests/research/test_evaluation.py tests/research/test_benchmark.py
```

The first command freezes selection, references, source files and saved control texts without API calls. The second makes paid requests for records that do not yet exist. Existing terminal records and interrupted `started` records are skipped, never silently retried; inspect interrupted records before any manual continuation. Frozen-source and image hashes must still match. A fresh directory makes a separate trial. Inference is nondeterministic; identical inputs do not guarantee identical text. To verify the committed results offline, load each JSON bundle row and call `text_score(row["sample"]["reference"], transcript)` for the Luna and control texts, then compare its `scores` entries.

Validation: 61 relevant offline tests passed, including five focused tests for unordered geometry removal, preserved known order, repeated-word accounting, tolerant versus literal fidelity, and empty outputs. All 33 retained results were independently rescored against the frozen references; result hashes and word denominators were checked. No product behavior or dataset annotations changed.
